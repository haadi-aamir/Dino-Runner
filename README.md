# Dinosaur Runner

A simple browser-based dinosaur runner game built with HTML, CSS, and vanilla JavaScript.

This project was created as a hands-on learning exercise to practise JavaScript fundamentals and understand how browser games work.

## Features

- Dinosaur movement and jumping
- Gravity and basic physics
- Time-based game loop using `requestAnimationFrame` and delta time
- Cactus obstacles with automatic spawning
- Collision detection
- Running animation
- Score tracking
- Game-over functionality

## Controls

| Key   | Action |
| ----- | ------ |
| Space | Jump   |

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES Modules)

## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/haadi-aamir/Dino-Runner.git
   ```

2. Navigate into the project folder:

   ```bash
   cd Dino-Runnder
   ```

3. Start a local development server:

   ```bash
   python -m http.server 8000
   ```

4. Open your browser and visit:

   ```text
   http://localhost:8000
   ```
